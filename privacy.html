โปรแกรมของเรา

TidyUp PC, NanoPDF และ NanoShare ทำงานบนเครื่องของคุณ ไฟล์ เอกสาร และข้อมูลในเครื่องไม่ถูกส่งมาที่เรา

เมื่อใส่ License Key โปรแกรมจะส่ง License Key, รหัสประจำเครื่องแบบ hash (SHA-256 ของรหัส Windows และข้อมูลฮาร์ดแวร์ ซึ่งแปลงกลับเป็นข้อมูลเดิมไม่ได้), ชื่อเครื่อง และเวอร์ชันโปรแกรม มาที่เรา เพื่อจำกัดให้ 1 Key ใช้ได้ 2 เครื่อง และตรวจซ้ำทุก 7 วันเมื่อต่ออินเทอร์เน็ต คุณดูและเอาเครื่องออกได้ที่หน้าบัญชีของฉัน

NanoShare ส่งไฟล์จากเครื่องถึงเครื่องโดยตรงและเข้ารหัสตลอดทาง เซิร์ฟเวอร์ของเราทำหน้าที่แค่ช่วยให้สองเครื่องเชื่อมต่อกัน และไม่เก็บไฟล์ของคุณ

โปรแกรมตรวจหาเวอร์ชันใหม่จาก GitHub ซึ่งเป็นที่เก็บไฟล์ติดตั้งของเรา

การเข้าสู่ระบบด้วย Google

เมื่อคุณเข้าสู่ระบบที่หน้าบัญชีของฉัน เราได้รับจาก Google เพียงชื่อ อีเมล และรหัสบัญชี Google ของคุณ เราไม่ได้รับรหัสผ่าน และไม่เข้าถึงข้อมูลอื่นในบัญชี Google เช่น อีเมลในกล่องจดหมาย รายชื่อติดต่อ หรือไฟล์

การใช้ข้อมูลที่ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

ข้อมูลที่เราเก็บ

  • ชื่อและอีเมลจาก Google กับวันที่เข้าสู่ระบบล่าสุด
  • License Key ที่ออกให้อีเมลของคุณ รวมถึงชื่อที่แสดงใน Key และวันหมดอายุ
  • เครื่องที่ใช้ License Key: รหัสประจำเครื่องแบบ hash ชื่อเครื่อง เวอร์ชันโปรแกรม วันที่เริ่มใช้ และวันที่ตรวจล่าสุด
  • คำขอที่คุณแจ้งการสนับสนุน เช่น เลขอ้างอิงการโอนและข้อความถึงเรา
  • สลิปที่คุณแนบ ซึ่งระบบลบให้อัตโนมัติหลัง 90 วัน
  • คุกกี้เข้าสู่ระบบ 1 ตัว มีอายุ 30 วัน เราไม่ใช้คุกกี้โฆษณาหรือคุกกี้ติดตาม
  • ข้อมูลทางเทคนิคในบันทึกของระบบ เช่น IP address ใช้เพื่อความปลอดภัยและแก้ปัญหา และเก็บไว้ชั่วคราว

เราใช้ข้อมูลเพื่อ

แสดง License Key ในบัญชีของคุณ ตรวจสอบการสนับสนุน และติดต่อกลับเมื่อจำเป็น เราไม่ขายข้อมูลของคุณ และไม่แบ่งปันเพื่อการโฆษณา

ผู้ให้บริการที่เราใช้

Cloudflare ให้บริการเว็บไซต์และฐานข้อมูล Google ให้บริการเข้าสู่ระบบ และ GitHub เก็บไฟล์ติดตั้งโปรแกรม ผู้ให้บริการเหล่านี้ประมวลผลข้อมูลตามที่จำเป็นต่อการให้บริการเท่านั้น

สิทธิ์ของคุณ

คุณขอดู แก้ไข หรือลบข้อมูลบัญชีได้ทุกเมื่อ โดยส่งอีเมลจากบัญชีเดียวกันมาที่ support@nanohash.biz เมื่อลบบัญชีแล้ว License Key ที่ใส่ไว้ในโปรแกรมยังใช้งานได้ตามปกติ เพราะตรวจแบบออฟไลน์
