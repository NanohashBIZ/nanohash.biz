ส่งตรงเครื่องต่อเครื่อง

เข้ารหัส 2 ชั้น

คำถามที่พบบ่อย

ผู้รับต้องลงแอปหรือเข้าสู่ระบบไหม?

ไม่ต้อง ผู้รับเปิดลิงก์ สแกน QR หรือพิมพ์รหัสที่ share.nanohash.biz บนเบราว์เซอร์ได้เลย ทั้งคอมและมือถือ

ส่งไฟล์ใหญ่ได้แค่ไหน?

ส่งผ่านอินเทอร์เน็ตได้ฟรีครั้งละ 200 MB เข้าสู่ระบบด้วย Google ได้ครั้งละ 1 GB และถ้าสนับสนุนเรา ฿99 ครั้งเดียว ส่งได้ไม่จำกัดตลอดไป ผู้รับบนเบราว์เซอร์อื่นนอกจาก Chrome หรือ Edge และบนมือถือ ไฟล์ที่ใหญ่กว่า 200 MB จะถูกพักไว้ในหน่วยความจำก่อนบันทึก ไฟล์ที่ใหญ่มากจึงอาจรับไม่สำเร็จ

ทำไมบางครั้งเชื่อมต่อไม่ได้?

เพราะไฟล์ส่งตรงถึงกันโดยไม่ผ่านเซิร์ฟเวอร์กลาง เครือข่ายบางแห่ง เช่น ในองค์กร จึงอาจไม่ยอมให้เชื่อมต่อตรง ลองเปลี่ยนไปใช้ Wi-Fi อื่นหรือเน็ตมือถือ

ปิดหน้าต่างแล้วยังส่งอยู่ไหม?

ในแอป Windows ยังส่งต่อจากไอคอนมุมขวาล่าง ถ้ากดออกจากโปรแกรมการส่งจะหยุด บนเว็บต้องเปิดหน้านั้นค้างไว้จนอีกฝั่งรับเสร็จ

เครื่องต้องมีอะไรบ้าง?

Windows 10 (เวอร์ชัน 1809 ขึ้นไป) หรือ Windows 11 แบบ 64-bit และ Microsoft Edge WebView2 ซึ่งมีอยู่แล้วใน Windows 11 ถ้า Windows 10 ยังไม่มี ดาวน์โหลดได้ฟรีจาก Microsoft

ใช้ในบริษัทได้ไหม มีค่าใช้จ่ายไหม?

ใช้ได้ฟรีทั้งส่วนตัวและธุรกิจ ติดตั้งได้ทุกเครื่องของคุณ ไม่มีช่วงทดลองและไม่ต้องใช้ License Key ถ้าอยากส่งไฟล์ใหญ่กว่า 1 GB ต่อครั้ง สนับสนุนเรา ฿99 ครั้งเดียว ส่งได้ไม่จำกัดตลอดไป
